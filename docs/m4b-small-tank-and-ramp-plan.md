## 1. 我自行拍板的默认值（⚠️ 本节是起草时的初版，**部分已被试玩反馈修订，以顶部修订记录为准**）

| 决策 | 默认取法 | 理由与备选 |
|---|---|---|
| 缩小后速度 | **不缩**（`MoveSpeed` 1600 / `TurnSpeed` 60 / 炮塔与俯仰转速不变） | 车小一半、速度不变 → 单位身长速度翻倍，手感更灵；跨场时间也没变。若要「一切等比」，把这几个值也乘 0.5 |
| 摄像机臂长 | **跟缩到 475**（`bScaleCameraWithVehicle = true`） | 保持第三人称观感比例。若想让「屏幕上也更小、看得更远」，把它关掉、臂长留 950 |
| 「随机一个面」的范围 | **只在朝外的面里随机**；两块中央掩体各一道坡 | 掩体与场地中心之间是 1800cm 中央大道，若随机到朝向大道那一面，坡会把主通路堵死。两块都加坡 → 东西两侧玩家都够得着 |
| 坡贴哪个边 | 坡**贴长边**（±Y 面，面宽 1400） | 长边放坡视觉自然、坡宽 600cm ≫ 车宽 175cm；短边只有 400cm 会很局促 |
| 坠落伤害 | 保持**没有**（现状本来就没有），并在代码里写明 | 见 §4 C2-5 |
| 坡的随机性 | 生成时随机一次、**存进关卡**后固定 | 「每次进游戏都变」会让人没法记地形，不符合对战需求 |

## 2. A｜血条上方显示玩家 ID（`BattleHUD`）

现状：`DrawOverheadBars` 只画 110×10 红条，锚点硬编码 `TankLoc + (0,0,240)`。

改法：
1. **取名字**：`Tank->GetController()->PlayerState->GetPlayerName()`；PS 为空就只画血条、跳过名字（重生瞬间会遇到）。
2. **画在血条上方**：`GetTextSize()` 量宽 → 先 `DrawRect` 一层半透明深底，再画白字（`GEngine->GetSmallFont()`），保证任何背景都读得清。
3. **锚点改为按碰撞盒推算**：`TankLoc.Z + GetSimpleCollisionHalfHeight() * 2 + 8`。这样 B 项缩放后血条与名字自动跟着降下来，彻底去掉硬编码 240（缩放前 ≈244，缩放后 ≈126）。
4. 遮挡剔除、距离剔除、`Projected.Z > 0` 判据**全部沿用**，名字与血条同生共死，不单独判断。

## 3. B｜坦克缩小到 1/2（`TankPawn`）

做法：加 `VehicleScale = 0.5`，在**构造函数**里把根组件（`CollisionBox`）的相对缩放设成它 →
所有子组件（车体 / 履带 / 12 个负重轮 / 炮塔 / 火炮 / 弹簧臂 / 摄像机）自动等比缩放，
且客户端与服务器各自构造时都会设，不依赖复制（`FRepMovement` 本来就不带缩放）。

| 量 | 现在 | 缩放后 |
|---|---|---|
| 碰撞盒（长×宽×高） | 760 × 350 × 236 | **380 × 175 × 118** |
| 负重轮滚动半径 | 35（网格局部） | 世界 **17.5** |
| 履带间距 `TrackSpan` | 278.4 | 世界 **139.2** |
| 摄像机臂长 | 950 | **475** |
| 血条/名字锚点高度 | 240（硬编码） | 由碰撞盒算，≈**126** |

**必须跟着改的「世界单位 ↔ 局部长度」混算点**（不改会静默出错，不报编译错）：

1. `HalfSpan = TrackSpan * 0.5f` —— 履带差速把「偏航角速度 × 半轮距」换算成左右履带线速度，必须乘 `VehicleScale`
2. `UpdateWheelSpin` 的 `RoadWheelRollRadius = 35` —— 网格缩了一半，同样的线速度下轮子应该转**两倍快**，用 `35 * VehicleScale`
3. 履带 UV 滚动 `TrackUVSpeedScale` —— 除以 `VehicleScale`，保持履带纹理的视觉速度一致
4. HUD 血条/名字锚点 —— 改为由碰撞盒推算（见 §2-3）

**不需要改的**（都是局部空间，自动跟着缩放）：
各 Mesh 的 `SetRelativeLocation`（车体 -120、负重轮 X 偏移、`GunPivot` (170,0,31)、后坐力 -12）、
`MuzzleForwardOffset`（走 `GetComponentTransform()`，局部→世界自动带缩放）、轮子 `SetRelativeRotation`、`RecoilDistance`。

**速度/距离类不改**：`MoveSpeed` / `TurnSpeed` / `TurretRotateSpeed` / `PitchSpeed` / `PushStrength` /
`PushConsumeSpeed` / 出生环半径 2300（理由见 §1）。

## 4. C｜中央掩体加坡 + 地形跟随

### C1 关卡：随机一个朝外的面加坡（新脚本 `Scripts/level/level_center_ramp.py`）

- 目标掩体：`Cover_Center_L @ (-1600, 4600)`、`Cover_Center_R @ (1600, 4600)`，各 1400 × 400 × 500，
  底面 Z = -40、顶面 Z = 460（与 `level_cover_fix.py` 的现状一致）
- 每块随机挑一个**朝外的面**（L 取 -X / +Y / -Y，R 取 +X / +Y / -Y），在该面外侧生成一道坡：

| 参数 | 值 |
|---|---|
| 坡度 | **25°**（< 可行走上限 30°，留 5° 余量） |
| 水平投影（run） | 500 / tan25° ≈ **1072** |
| 斜面长（slope） | 500 / sin25° ≈ **1183** |
| 宽 × 厚 | **600 × 60** |

- 坡顶边**与掩体顶面齐平并向掩体内重叠 20cm**（不留缝、不产生台阶）；坡底边与地面顶面（Z=-40）齐平
- 用 `Engine/BasicShapes/Cube` + 与掩体一致的材质（沿用灰盒惯例）；旋转用
  `unreal.KismetMathLibrary.make_rot_from_xz(上坡方向, 坡面法线)` 构造，避免手推欧拉角出错
- **幂等**：先按 `Ramp_` 前缀清旧件再生成；末尾复核（坡度 / 顶面是否齐平 / 底边是否贴地 / 坡宽）并保存关卡
- 打印这次随机到的是「哪一块的哪一面」，便于复现

### C2 移动：新增「地形跟随」段（`TankPawn`）

现状问题：位移只用 `AddActorLocalOffset` 做**水平**扫掠，没有重力、没有贴地、不处理坡面 ——
所以任何坡都会像墙一样把车挡住，「能爬上去 / 能摔下来」都做不到。

新增 `UpdateGroundContact(DeltaTime)`，**只在 `IsLocallyControlled()` 实例上跑**
（与炮塔伺服同一套思路：远端实例的位置由复制决定，跑地形跟随会和复制打架）。

1. **地面探测**：从碰撞盒底部往上 10cm 起，向下打 `ECC_Visibility` 射线，距离 = 半高 + `GroundSnapDownDistance`。
   坦克的 `Pawn` profile 对 Visibility 是 Ignore → 不会「贴到别的坦克」上，只认地面/掩体/坡
2. **贴地 + 法线对齐**：命中且 `ImpactNormal.Z ≥ cos(MaxClimbSlopeDeg)` → 车底对齐到命中点、清垂直速度；
   并按法线倾斜车身（**只改 pitch/roll，保留 yaw**，`RInterpTo` 平滑）
3. **上坡**：水平扫掠若被**可行走**的面挡住（法线 Z ≥ cos30°）→ 把剩余位移**投影到该面**再走一次（slide），
   于是 25° 坡上每帧「沿坡往上 + 往前」，自然爬上去
4. **坠落**：探测不到地面（走出掩体边缘）→ 进入空中，`VerticalVelocity += GroundGravityZ * dt` 向下扫掠；
   落回可行走面即落地、垂直速度归零
5. **无坠落伤害**：本工程**本来就没有任何坠落伤害逻辑** ——
   `grep -n "FallDamage|Landed|ApplyDamage"` 只命中坦克/墙的血量组件，`ATankPawn::TakeDamage` 只由炮弹命中调用。
   本段不会引入，并在代码里写死注释「落地不调用 TakeDamage」，防止以后有人误加

新增参数（都 `EditAnywhere`，可现场调）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `VehicleScale` | 0.5 | 整车缩放 |
| `MaxClimbSlopeDeg` | 30 | 可行走坡度上限（坡 25° 有 5° 余量） |
| `MaxStepUp` | 15 | 上下台阶容差。**必须远小于边界台阶的 100**，否则车能翻过边界 |
| `GroundSnapDownDistance` | 60 | 超过这个距离没地面就判定为空中 |
| `GroundGravityZ` | -980 | 重力加速度 |
| `GroundAlignSpeed` | 6 | 车身随坡面倾斜的平滑速率 |

### C3 与现有系统的交互（回归风险清单）

| 系统 | 影响 | 处置 |
|---|---|---|
| 推挤 / 被推位移 | 推挤是纯世界空间位移，与车体尺寸无关 | 不动 |
| 客户端权威上报 | `ServerSyncTransform` 传 `GetActorRotation()`，pitch/roll 也在 FRotator 里 | 爬坡姿态会正常复制到其他端，无需改 |
| 边界台阶（高 100） | 竖直面法线 Z = 0 → 不可行走，且 `MaxStepUp = 15 < 100` | 双保险继续挡死 |
| 出生点 | 出生环半径 2300 不变 | 车变小后相对更宽松，不需要动 |
| 阵亡镜头 / 死亡特效 | 用的是死亡位置 + 固定偏移 | 不动 |
